## 0. 文档说明

1. 本文档细化系统的**非功能性需求**与**数据规则**，为性能验收、安全合规评审、数据模型设计提供可量化依据。
2. 需求编号：性能（NFR）、安全（SEC）、合规（CMP）、内容安全（CNT）、数据规则（DAT）、可观测与评估（OBS）。
3. 所有量化指标均为**验收阈值**；未达成视为不通过，除非经评审调整。
4. 字段名采用英文小写下划线风格；中文名用于展示，首次出现写「中文（English）」。
5. 技术细节引用基线冻结的 Java 技术栈组件（如 Spring Security 6、pgvector、Lucene BM25、bge-m3、Langfuse），但本文档以指标与规则为准，不涉及实现。

### 6.3 权限标签模型

1. **密级（security_level）**：`public`（公开）/ `internal`（内部）/ `confidential`（机密）/ `core`（核心）。
2. **可见性（visibility）**：`tenant_all`（租户内可见）/ `space`（空间内可见）/ `group`（指定用户组）/ `user`（指定用户）/ `self`（仅本人）。
3. **访问控制（ACL）**：`allow` / `deny`，Deny 优先于 Allow；继承顺序为「文档显式 ACL → 空间 ACL → 租户默认」。
4. **角色映射**：`admin` > `kb_admin` > `employee`；`developer` 仅通过 API Key 权限范围访问。
5. **隔离边界**：所有检索、预览、引用、导出必须同时校验 `tenant_id` + `security_level` + `visibility` + 用户 ACL。

|---|---|---|

| 文档类型 | 制度、SOP、手册、FAQ、合同、报表、技术方案 | 类型筛选与切分策略选择 |

### 6.5 数据规则条目

| 编号 | 规则 | 描述 |
|---|---|---|
| DAT-001 | 元数据规则 | 按 6.1 字段表落地，`tenant_id`、`space_id`、`title`、`business_domain`、`security_level`、`status` 必填。 |
| DAT-002 | 切分规则 | 按 6.2 参数执行，片段必须保留 `doc_id`、`chunk_id`、页码/章节锚点。 |
| DAT-003 | 权限规则 | 按 6.3 模型执行，Deny 优先，全链路强制执行。 |
| DAT-004 | 标签规则 | 标签字典统一管理，禁止自由文本标签，避免检索噪声。 |
| DAT-005 | 版本规则 | 重新上传生成新版本；检索仅指向当前生效版本；历史版本可查不可命中。 |
| DAT-006 | 保留规则 | 会话 90 天、记忆 180 天、审计 ≥ 180 天、原始文档 ≥ 3 年；到期自动销毁并留痕。 |
| DAT-007 | 脱敏规则 | PII/凭证在日志、trace、上下文中自动脱敏，识别率 ≥ 98%。 |
| DAT-008 | 删除规则 | 删除文档需级联清理 pgvector 向量、Lucene 倒排、缓存与派生索引，30 天内完成物理清理。 |
| DAT-009 | 向量规则 | 向量由 bge-m3 生成，维度与索引一致；文档删除后向量不可命中且随保留策略清理。 |

## 7. 可观测与评估需求（OBS）

| 编号 | 需求项 | 描述 | 量化/验收指标 | 阶段 |
|---|---|---|---|---|
| OBS-001 | 全链路 trace | 每次 LLM 调用、检索、工具调用生成 Langfuse trace | LLM 调用 trace 覆盖率 100%；`trace_id` 贯穿问答全链路 | MVP |
| OBS-002 | 指标采集 | Micrometer + Prometheus 采集问答量、命中率、延迟、错误率、工具调用、存储用量 | 核心指标齐全；采样率 100% | V1 |
| OBS-003 | 日志规范 | 结构化日志（Logback/JSON），字段含 `tenant_id`、`user_id`、`trace_id`、模块、级别、耗时 | 日志可检索可聚合 | MVP |
| OBS-004 | 告警 | 延迟、错误率、队列积压、配额、模型不可用告警 | 告警触达 ≤ 1 分钟；误报率 ≤ 5% | V1 |
| OBS-005 | RAG 评估 | 离线/在线评估检索与生成质量 | 评估集覆盖 ≥ 3 个业务域；指标口径统一 | V1 |
| OBS-006 | 评估指标定义 | 统一指标口径（见 7.1） | 指标定义文档化并冻结 | V1 |
| OBS-007 | 评估闭环 | 评估报告驱动优化 | 优化前后指标可比；报告可导出 | V1 |
| OBS-008 | 成本观测 | 模型调用与存储成本可观测 | 按租户/部门统计成本 | V2 |

### 7.1 评估指标定义

| 指标 | 定义 | 目标值 |
|---|---|---|
| 检索召回率（Recall@K） | 相关文档片段中被召回的比例 | ≥ 90% |
| 引用准确率（Citation Accuracy） | 引用片段能支撑答案陈述的比例 | ≥ 90% |
| 无依据回答率（Hallucination Rate） | 无可靠引用支撑的事实性回答占比 | ≤ 5% |
| 答案相关性（Relevance） | 人工/模型评分的答案与问题相关性均值 | ≥ 4.0 / 5 |
| 拒答率（Refusal Rate） | 明确拒答的会话占比 | ≤ 20% |
| 首 token 延迟（TTFT） | 提问到首 token 的时间 | P95 ≤ 3s |
| 端到端延迟（E2E Latency） | 提问到答案结束的时间 | P95 ≤ 15s |
| 工具调用成功率 | 工具调用成功次数 / 调用总次数 | ≥ 99% |
| 用户满意度 | 点赞数 /（点赞+点踩） | ≥ 85% |
| trace 覆盖率 | 有 trace 的 LLM 调用 / 总 LLM 调用 | 100% |
