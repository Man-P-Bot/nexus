# 文档导航

本项目按企业开发流程组织文档，阅读建议：**基线 → 立项 → 需求 → 设计 → 计划风险 → 交接任务**。

## 目录结构

```
docs/
├── 00-项目基线/        项目基线与统一约定（唯一权威基线）
├── 01-立项与背景/      立项报告 / 可行性 / 热点与竞品
├── 02-需求分析/        需求规格 / 角色用例 / 非功能与数据
├── 03-系统设计/        架构 / 选型 / 详细设计 / 数据库 / 接口 / 安全
├── 04-计划与风险/      项目计划与里程碑 / 风险登记册
└── 05-交接与任务/      任务记录 / 交接文档 / 给下一个AI的开发指引
```

## 推荐阅读路径

| 身份 | 推荐先读 |
|---|---|
| 决策者 / 面试官 | 01 立项 → 03 热点竞品 → 07 架构 → README |
| 产品经理 | 04 需求规格 → 05 角色用例 → 06 非功能 |
| 架构师 / 后端 | 07 架构 → 08 选型 → 09 详细设计 → 10 数据库 → 11 接口 → 12 安全 |
| 新接手的开发者 / AI | 16 交接 → 17 开发指引 → 00 基线 → 15 任务记录 |
| 项目经理 | 13 计划 → 14 风险 → 16 交接 |
