## 三、关键决策（已冻结，需变更请评审）

1. **Agent 编排选 LangGraph4j**，而非纯提示编排 / 其他 Agent 框架：状态图显式建模，可循环与人工审批，可控性最强。
2. **检索选 Lucene BM25 + pgvector 向量混合**，RRF 融合后 Rerank：兼顾关键词精确匹配与语义召回，缓解幻觉。
3. **向量库 pgvector 为主**（与业务库同库），Milvus 备选：同库部署运维成本低，过滤检索能力满足需求。
4. **模型混合策略**：DeepSeek-V3 主力 + Qwen2.5 备选 + Ollama 本地兜底，保证私有化与成本可控。
5. **工具接入统一走 MCP**：工具/数据源标准化，Function Calling 桥接。
6. **评估与可观测内建**：每次 LLM 调用有 trace，每个 RAG 结果有评估分，作为上线门禁。
