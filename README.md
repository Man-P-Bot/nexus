# 星枢 Nexus · 企业智能知识库与问答智能体平台（NKAP）

> 面向 B 端企业的私有化 AI 知识平台：把企业内部文档统一接入，通过 **RAG + Agent 编排**，
> 为员工提供**可溯源、带权限、可扩展**的智能问答与业务协同能力。

- 阶段：**设计阶段（Phase 2）** ｜ 当前交付：全套前期文档，尚未编码
- 技术栈：Java 21 · Spring Boot 3 · Spring AI · LangChain4j · LangGraph4j · pgvector · PostgreSQL · Redis · RabbitMQ · MinIO · MCP · Langfuse
- 文档规范：企业开发流程，编号化需求 / 设计 / 风险，便于交接与续作
- 技术背景契合：以 Spring Boot 企业级微服务为主线，AI 侧用 Spring AI / LangChain4j / LangGraph4j / MCP 体现「给 Java 项目接入 AI」的工程化能力

---

## 一、为什么做这个项目

1. **知识分散**：制度、SOP、产品文档散落在 Wiki / 网盘 / 群聊，检索靠人工。
2. **回答不可信**：传统关键词检索只给链接，员工仍要自行阅读判断。
3. **重复劳动**：HR / IT / 客服 / 运维等支持岗大量重复解答相同问题。
4. **权限与合规**：知识接入 AI 后，「谁能问、能问什么、能看到哪段原文」必须可控可审计。
5. **接入成本高**：业务工具不统一，AI 难以调用真实业务数据。

---

## 二、项目目标（北极星指标）

- 员工 **2 次点击内**获得「带原文引用、可验证」的答案。
- 支持类岗位重复咨询量下降 **30%**。
- 首期接入 **≥3 业务域、≥1000 文档、≥50 API 工具**。
- RAG 引用准确率 **≥90%**，无依据回答率 **≤5%**。

## 四、核心架构一览

```
接入层    Nginx / OIDC SSO / Spring Security 网关 / WebFlux SseEmitter 流式
应用层    知识库管理  文档管线  检索引擎  Agent编排
          会话记忆    引用溯源  管理观测  开放平台
能力层    LLM 网关(Spring AI, DeepSeek/Qwen/Ollama)  工具与 MCP 网关
数据层    PostgreSQL(+pgvector)  Lucene BM25  Redis  MinIO
基础设施  Docker Compose / Kubernetes / Langfuse / Micrometer + Prometheus
```

核心数据流：`提问 → 查询改写 → 权限过滤混合检索 → 重排 → 上下文组装 → Agent/工具调用 → LLM 生成 → 引用校验 → 流式返回`
